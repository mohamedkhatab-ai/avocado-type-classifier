# 🥑 Avocado Intelligence Platform

Deep Learning & Ensemble Analytics Dashboard for Organic vs. Conventional Avocado Classification built with PyTorch, AdaBoost, and Streamlit.

## 🚀 Features
- **AdaBoost & PyTorch MLP Models**: High-accuracy binary classification (>98% test accuracy).
- **Interactive Streamlit UI**: Hyperparameter tuning, dataset sampler, and real-time inference engine.
- **Visual Analytics**: Interactive Plotly charts for volume, price distribution, and feature importance.
